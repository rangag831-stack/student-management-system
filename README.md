Title : Student Management System using Django

Project Description :
Developed a web-based Student Management System using the Django framework to efficiently manage student records through a dynamic and scalable interface. The application supports full CRUD (Create, Read, Update, Delete) operations, allowing users to add, update, delete, and view student information. Implemented Django Models to design the database schema and used Django ORM for seamless database interactions. The project follows the MVT (Model-View-Template) architecture, ensuring clean separation of logic and presentation. Additionally, it includes form handling, URL routing, and template rendering, demonstrating practical backend development skills using Django.

Key Features
•  Add, update, delete, and view student records (CRUD operations) 
•  Database integration using Django ORM 
•  User-friendly web interface using Django Templates 
•  Form handling and validation 
•  URL routing for multiple pages 
•  Scalable MVT architecture 
•  Admin panel for managing student data

Technologies Used
•  Framework: Django 
•  Programming Language: Python 
•  Frontend: HTML, CSS (Basic) 
•  Database: SQLite (default Django DB) 
•  Concepts: MVT Architecture, ORM, CRUD Operations
